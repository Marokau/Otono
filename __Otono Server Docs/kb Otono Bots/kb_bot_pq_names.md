# Dedicated PQ character names

Existing crews use a PQ prefix, class label and numeric suffix, preserving character identity and progression:

| Crew | Prefix | Example |
| --- | --- | --- |
| Kerning | KPq | KPqThief1 |
| Ludibrium | LPq | LPqMage1 |
| Ludibrium Maze | LMPq | LMPqSpear1 |
| Orbis | OPq | OPqMage1 |
| Magatia | MPq | MPqMage1 |
| Carnival | CPq | CPqArcher1 |
| Zakum | Zakum | ZakumBishop1 |

Owner-selected prefixes for future crews: Horn, Pink, GPq, APq, CPq2, PPq, CWKPq.
These are naming preferences, not implemented crews or a statement of PQ availability.
Character names must be 3-12 ASCII letters/digits. Shorten class labels when needed,
Keep the prefix and numeric suffix within that limit. Horntail uses Horn (for example, HornBishop1).
Reuse eligible registered fixtures instead of creating a fresh batch for each attempt.

MV's Lair PQ uses the owner's MVPQ abbreviation and the future dedicated prefix MVPq, with class and numeric suffix, for example MVPqMage1 or MVPqThief1. Keep names within the existing character-name length limit. This records a naming convention only; dedicated MV's Lair companions are not implemented.
