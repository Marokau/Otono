Owner-selected prefixes for future crews: Pink, APq, CPq2, PPq, CWKPq.
These are naming preferences, not implemented crews or a statement of PQ availability.
Character names must be 3-12 ASCII letters/digits. Shorten class labels when needed,
Keep the prefix and numeric suffix within that limit. Horntail uses Horn (for example, HornBishop1).
Reuse eligible registered fixtures instead of creating a fresh batch for each attempt.

MV's Lair PQ uses the MVPQ abbreviation and dedicated prefix MVPq with class and numeric suffix: MVPqBishop1, MVPqSpear1, MVPqArcher1, MVPqThief1 and MVPqSword1. Keep names within the existing character-name length limit. Dedicated companions are implemented and have completed a bot-only run through rewards and normal exit; a human-client audit remains pending.
